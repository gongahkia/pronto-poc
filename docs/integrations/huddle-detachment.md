# Huddle detachment

The user requested removal from Pronto on 19 November 2026. The browser widget,
launchers, anchors, refresh hooks, HTTP routes, adapters, SDK dependencies,
vendored archives and dedicated feedback CI/tests are retired. Guest display
names are generated by Pronto; chooser sessions and staff capabilities remain.
Customer satisfaction ratings (`/csat`) are a separate product feature and remain.

Before detachment, the existing named operator put the verified hosted store in
readonly mode through the existing control CLI and exported a complete
`huddle.feedback.v2` snapshot: 8 threads, 13 comments and 21 history entries.
The export and storage inventory are private under
`output/instagram-public/huddle-detach-*` and `huddle-retention-*`. Original
accounts, feedback tables, metadata and migration history are retained; no
storage-deletion migration runs. Future reads/recovery require deliberate
administration or restoring the matching integration from Git history. The old
feedback control and one-off migration CLIs are no longer installed.

General PostgreSQL fixture tooling remains as `pnpm fixtures:postgres` and
`pnpm test:isolated:db`, with optional `--test-file` or `--eval`. Each check owns
its marked database and cleans up only that fixture. Historical Huddle-specific
commands in older documents are retired.

Huddle itself already provides package/framework installation helpers,
standalone `embed.js` / `local-embed.js` scripts, explicit database installers,
and browser cleanup via `destroy()`. Its README and server matrix document and
test manual package/route removal with data retention. Inspection of the sibling
Huddle repository found no end-to-end installer/uninstaller command that discovers
and removes host-specific imports, wrappers, routes, configuration and packages.
That automation is the tooling gap for a follow-up in Huddle; its repository was
inspected without modification. Storage deletion must remain a separate explicit
choice after a verified complete export.
